# 100 questions for the Ikshaa chat assistant
#
# Written fresh for this audit. NONE of these come from eval/corpus.js — the
# bot was tuned against that corpus, so scoring it there measures the
# questions we already thought of. These are the ones we did not.
#
# Deliberately mixed: formal and casual, typos and shorthand, single-topic and
# compound, and a tail of things the villa has no facts for at all. That tail
# is the point. Answering it confidently is the failure mode that matters.
#
# One question per line. Blank lines and # comments are ignored.

# =============================================================================
# CONVERSATIONS — lines starting with ">" continue the previous one.
#
# Everything above is a single turn against a fresh assistant. These are not:
# each block is one guest talking, so the bot's memory, its topic and its
# count of what has already been asked all carry across the lines.
#
# This is where repetition is tested. A guest who asks the same thing three
# different ways has asked once, and should be answered as such.
# =============================================================================

# ---- the same question, three ways ----
how much does it cost
> what are your rates
> whats the price for a week

# ---- a repeat with something else in between ----
is there a pool
> how do we get from the airport
> is there a swimming pool

# ---- repeating an unanswerable one ----
are there cameras in the house
> do you record inside the villa

# ---- memory: dates given once, used later ----
we want to come 12 December for 3 nights
> there are 4 of us
> is that available

# ---- follow-up that leans on the last topic ----
tell me about the pool
> is it heated
> is it safe for children

# ---- correcting themselves ----
we are 6 people
> sorry make that 8
> is that too many

# ---- a guest getting frustrated ----
what does it cost
> you have not answered my question
> just tell me the price
